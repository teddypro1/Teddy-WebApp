# CodeAssist IDE Reference

এই ফোল্ডারে Teddy-WebApp উন্নয়নের সময় ব্যবহারকারীর CodeAssist IDE থেকে দেওয়া স্ক্রিনশট-ভিত্তিক নির্দেশিকা রাখা হয়।

## Reference index

- [Git এবং Source Control](source-control.md) — Branches, repository menu, History, Stashes, GitHub integration, Fetch, Pull, Push এবং দৃশ্যমান sync status।
- [Modules ও Android Module Settings](modules-and-android-settings.md) — Modules screen, app module, Java/SDK/version configuration, Build Types, Build Features, Compiler plugins, Packaging, Signing/Keystore Manager, Dependencies, Build & Run এবং Privacy & Data settings।

## Documentation rules

- কেবল স্ক্রিনশটে দৃশ্যমান তথ্য বা ব্যবহারকারীর স্পষ্ট ব্যাখ্যা নথিভুক্ত করতে হবে।
- IDE-এর cached/local branch list-কে GitHub-এর live branch list হিসেবে ধরা যাবে না।
- প্রতিটি নতুন screenshot batch দেখে সংশ্লিষ্ট reference ফাইল হালনাগাদ করতে হবে।
- ব্যক্তিগত ইমেইল, access token, password বা অন্য কোনো secret নথিভুক্ত করা যাবে না।
- এটি CodeAssist interface reference; app feature বা Build success-এর প্রমাণ নয়।
